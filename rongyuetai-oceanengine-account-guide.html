巨量引擎账号申请流程

荣悦台只负责企业资质认证；认证通过后的技术操作全部由我们完成。

1进入巨量引擎开放平台

登录巨量引擎工作台。

找到“巨量引擎开放平台”，点击进入。

点击右上角“开发者后台”。

2荣悦台申请开发者资质

荣悦台按照下面的表格填写即可，不需要学习后面的技术操作。

页面内容怎么填写或选择
企业主体名称南京荣悦台餐饮管理有限责任公司
统一社会信用代码填写营业执照上的18位代码
企业联系人填写能接收短信和邮件的联系人
开发者类型如果出现，选择客户
代码类型选择企业营业执照统一社会信用代码
账号管理身份优先选择法人
对公验证使用荣悦台公司的对公银行账户
CA签章与合同使用荣悦台公司主体完成
不要选择：代理商、第三方服务开发、个体工商户。法人能够配合时，不选代理人。
提交前核对：公司名称和统一社会信用代码必须与营业执照完全一致。主体资质通过后不能修改。

荣悦台只需要配合五件事

  1. 提供营业执照信息。
  2. 接收手机验证码。
  3. 法人完成身份验证。
  4. 使用公司对公账户完成验证。
  5. 完成 CA 签章和电子合同。

3资质通过后由我们操作

我们继续使用现在这个开发者账号登录，进入开发者后台创建应用。

必须选择：自研投放系统 → 我是客户

不要选择“提供第三方服务”，也不要选择“我是代理商客户”。

之后由我们完成创建应用、申请本地推 API 权限、配置回调、账号授权、获取 Token 和真实接口测试。

荣悦台负责认证资质，我们负责后续全部技术操作。
