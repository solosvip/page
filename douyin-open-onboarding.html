现在不要点击“绑定开发者”

“绑定开发者”只适用于已经拥有抖音开放平台账号的情况。荣悦台当前尚未入驻，应先点击“入驻开放平台”。

2第二步

设置开放平台登录账号

页面底部的“注册入驻信息”用于自动创建抖音开放平台账号。

填写说明
手机号
优先填写当前抖音来客管理员使用、且公司可以长期控制的手机号
验证码
点击“发送验证码”，由手机号持有人提供本次验证码
设置登录密码
设置专门用于抖音开放平台的密码
再次确认密码
与上一项完全一致

账号必须长期可控

后续登录开放平台、绑定来客和处理审核问题都可能需要验证码。不要使用临时手机号，也不要使用离职后无法找回的个人手机号。

✓入驻成功以后

后面由我们操作

入驻审核通过后，我们继续使用这个账号完成：

  1. 在抖音来客绑定开发者
  2. 进入抖音开放平台开发者后台
  3. 创建“生活服务商家应用”
  4. 申请线索查询解决方案和 life.crm.clue.query 权限

绑定开发者、创建应用、申请接口权限和真实 API 测试，全部由我们负责。
